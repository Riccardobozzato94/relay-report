# RelayReport

Prepara il report mensile per un cliente. Inserisci i numeri, premi "Prepara il report", rileggi il testo, firma e poi invia.

**Apri lo strumento:** https://riccardobozzato94.github.io/relay-report/

Nessun account, nessuna installazione, nessun costo. Tutti i dati sono di esempio e nessun invio è automatico.
